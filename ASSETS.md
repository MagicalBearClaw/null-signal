# Asset Manifest

Every third-party asset used in a shipped build must be listed here, and its attribution added to the in-game Credits (`src/ui/menu/credits.ts`). Source files live in the private `null-signal-assets` repo, never in this one.

Accepted licenses: Fab Standard License, CC0, CC-BY (attribution goes in in-game Credits), Mixamo (Adobe terms).
Rejected: Fab Legacy License, Reference Only, Personal-use-only, anything unclear.
